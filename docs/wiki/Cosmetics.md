# Cosmetics & Armor Appearance

[← Home](Home.md) · [Recipes](Recipes.md)

The mod supplies **four cosmetic equipment slots**—head, chest, legs, feet—separate from protective armor. They can be used to create outfits and visual transformations without sacrificing armor stats.

## Cosmetic controls

Open the cosmetic equipment screen through the extra inventory control. The **hide armor** option hides visible armor, while the underlying equipped armor and its stats remain active. The setting is synchronized so other players can see the cosmetic appearance.

A **Cosmetic Guide** gives in-game previews and information.

**Guide recipe:** book + brush (shapeless).

## Special cosmetic items

| Item | Slot(s) | Effect |
| --- | --- | --- |
| End rod / colored end rod | Head / Chest / Legs / Feet | Angled head rod, rod arms and rib effects, rod legs |
| Lightning rod | Head | Angled metal rod |
| Flower | Head | Flower crown |
| Flower | Feet | Flower-colored particle trail |
| Crystal / amethyst cluster | Head | Crystal mohawk and upper-back spine |
| Mob head | Head | Replaces/hides underlying player head visually |
| Bone | All four | Custom 3D bone-block-textured skeleton components |
| Blaze powder | Head / Feet | Flame halo or ember trail |
| Nautilus shell | All four | Shell, kelp and seabed-themed outfit details |
| Echo shard | Feet | Sculk-soul particles |
| Slime ball | Feet | Slime particles |
| Gunpowder | Feet | Smoke trail |

Ordinary block items and matching equippable items can also be accepted in compatible slots.

## Snow golem transformation

Equip this combination:

| Slot | Item |
| --- | --- |
| Head | Carved Pumpkin |
| Chest | Stick |
| Legs | Snow Block |
| Feet | Snow Block |

The appearance changes to a controllable snow-golem-style player model.

## Armor stands

Armor stands can display supported cosmetic effects. Sneak-right-click with a compatible head cosmetic to assign it to an armor stand's head.

## Death behavior

With Keep Inventory disabled, cosmetic slot items drop on death. The armor visibility preference is persistent and synchronized.
