# Caszual Additions Wiki

**Minecraft Java 26.2 • Fabric**

Caszual Additions combines building tools, decorative features, storage, XP utilities, cosmetics and useful gameplay additions into one mod. It also provides a shared creative inventory group for compatible Caszual companion mods.

## Quick highlights

| Feature | Description |
| --- | --- |
| Pallets | 2×2 inventory block storing 216 item stacks (eight single chests), with a limited three-dimensional item display |
| Quarter blocks | Paint a quarter-block template with almost any block's appearance; place sections individually |
| RGB blocks | Animated RGB end rods plus an RGB building-block family |
| XP network | Store experience and use it to repair Mending tools or feed an XP shower |
| Cosmetics | Four additional cosmetic equipment slots; hide visible armor while keeping its protection |
| Head vending | Purchase player, vanilla mob and searchable decorative custom heads for one emerald |
| Player plushie | Craft a decorative player-themed plushie from a player head |
| Size snacks | Shrink, grow and reset player scale |
| Firefly glass | Decorative enclosures with configurable colored particles |
| Unbreakable utility | Unbreakable anvil and an associated book |

**Documentation scope:** This wiki describes items and functionality present in the repository's `main` branch. Features proposed for other Caszual mods are not implicitly included.
